HCF AND LCM of an Array Or 2 numbers


#include <bits/stdc++.h>
using namespace std;

int main() {
    vector<int> arr = {12, 18, 24};

    int n = arr.size();

    int g = arr[0];
    int l = arr[0];

    for (int i = 1; i < n; i++) {
        g = gcd(g, arr[i]);
        l = lcm(l, arr[i]);
    }

    cout << "GCD = " << g << endl;
    cout << "LCM = " << l << endl;

    return 0;
}

1. gcd(a, b) – Used to find the Greatest Common Divisor (GCD) of two numbers. It is available in the <numeric> header.
2. lcm(a, b) – Used to find the Least Common Multiple (LCM) of two numbers. It is available in the <numeric> header.

(Upper bound and Lower Bound ) ---> Works on Sorted Range

Easy way to remember
Function	Returns iterator to first element...
lower_bound(x)	>= x
upper_bound(x)	> x


Suppose:

vector<int> v = {1, 2, 2, 2, 4, 5, 7};

lower_bound(v.begin(), v.end(), 2);

returns an iterator pointing to the first element that is >= 2.

Here:

1  2  2  2  4  5  7
   ^
   first >= 2

So it points to the first 2.


upper_bound(v.begin(), v.end(), 2);

returns an iterator pointing to the first element that is > 2.

-------------------------------------------------------------------------------------------



1  2  2  2  4  5  7
            ^
            first > 2
